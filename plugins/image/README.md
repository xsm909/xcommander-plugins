# Images

A picture, shown rather than described. PNG, JPEG, GIF, WebP and BMP — the
formats the application can decode itself, which is why they are the ones
listed.

Zoom and pan with the mouse; Escape goes back to the panel, as it does
everywhere.

No code, so it loads on every platform the application runs on, including the
ones where running a plugin's code is not allowed at all.
